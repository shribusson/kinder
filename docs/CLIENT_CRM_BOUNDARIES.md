# Границы зон: Client Portal и CRM

Дата: 2026-03-03

## Архитектурный инвариант

Разделение зон сохраняется строго:

- `Client Portal`: пользовательская зона родителей/учеников.
- `CRM`: внутренняя зона сотрудников (администраторы/менеджеры/преподаватели).

Интеграция выполняется только через backend API, без прямых cross-import UI-зон.

## Зоны ответственности

### Client Portal отвечает за

- просмотр каталога программ/курсов;
- запись и управление заявками на обучение;
- расписание и посещаемость (read-first, ограниченный write);
- материалы и прогресс ученика;
- счета и оплаты.

### CRM отвечает за

- лид-менеджмент и pipeline;
- продажи и conversion в enrollment;
- управление учебными сущностями (программы, группы, расписание);
- операционные коммуникации (inbox/calls);
- аналитика воронки, обучения и выручки.

## Интеграционные контракты

1. `Lead Intake`: Client/Marketing -> CRM (создание лида).
2. `Enrollment Sync`: CRM -> Client (доступ к курсу после сделки/оплаты).
3. `Schedule Feed`: Education Core -> Client (расписание/обновления).
4. `Progress Feed`: Education Core -> Client и CRM (единый прогресс).
5. `Billing Status`: Billing -> Client и CRM (статусы счетов и оплат).

## Auth/RBAC правила

- Client роли: `parent`, `student` (ограниченный доступ к данным своей семьи).
- CRM роли: `admin`, `manager`, `teacher`, `support`.
- Раздельные route guards и policy checks по зонам.
- Общие identity/account связи в backend.

## API namespace (целевой)

- `/client/*` — безопасные клиентские операции.
- `/crm/*` — внутренние CRM-операции.
- `/public/*` — публичные marketing/end-user endpoints.
- `/webhooks/*` — внешние интеграции.

## Запрещенные паттерны

1. Прямая запись CRM-сущностей из Client UI минуя клиентский API-контракт.
2. Хранение ключевых бизнес-правил только во фронтенде.
3. Перекрестные UI-зависимости между `/app/client` и `/app/crm`.

## Definition of Done для границ

1. Маршрутная изоляция (`/client`, `/crm`) в middleware.
2. Раздельное меню/навигация для каждой зоны.
3. E2E-сценарий подтверждает сквозной flow без нарушения границ.
