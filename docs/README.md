## Принцип поддержки документации

1. Новые документы добавлять в `docs/` (а не в корень).
2. В корне держать только entry-point документы (`README`, `QUICKSTART`, `COMMANDS`) и файлы конфигурации.
3. При добавлении нового документа обновлять этот индекс.
